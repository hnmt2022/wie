# 活動写真（実写）

学習会・交流会・講師活動・作業風景など、Wieの実際の活動写真を置くフォルダです。

## ルール

- 実際に撮影した写真のみを置いてください（AI生成の人物写真や、活動実績に見える写実的な合成画像は置かないでください）。
- 顔が写っている写真は、掲載許可を確認したものだけを使用してください。
- 個人情報、参加者名、連絡先、書類の内容などが写り込んでいないか確認してください。
- WebPまたはAVIF形式を推奨します。表示サイズに対して過大なファイルは避けてください。

## 差し替え方法

1. このフォルダに画像ファイルを追加します（例: `2025-kakutei-shinkoku.webp`）。
2. `src/_data/activities.json` の該当する項目の `"image"` を `null` からそのファイル名に変更します。
3. `npm run build` でプレースホルダーから実写真に切り替わります。

## 推奨サイズ

- 一覧カード用: 4:3（例: 800×600px）
- ヒーロー相当で使う場合: 16:9（例: 1600×900px）
