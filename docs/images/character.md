# Wieちゃん（キャラクター画像）

団体キャラクター「Wieちゃん」の正式な画像を置くフォルダです。

## ルール

- 正式なWieちゃん画像が未配置の間、新しいキャラクターを勝手に生成しないでください。サイト側は自動的に控えめなテキストプレースホルダーを表示します。
- Wieちゃんはサイト全体の主役ではなく、「参加する」ページの案内、お知らせが無いときの表示、初めての人向けの補足、フッター付近の小さな案内など、親しみやすさを補う場面でのみ使用します。
- 企業・自治体向けの説明や、理念の中心部分では大きく使用しないでください。

## 差し替え方法

1. このフォルダに画像ファイルを追加します（例: `wiechan-default.webp`、正方形推奨）。
2. `src/_includes/partials/media.njk` の `wiechan` マクロ呼び出し箇所（`join.njk` / `news.njk` / `index.njk` / `404.njk`）で、`wiechan(null, ...)` の `null` をファイル名に変更します。
