# Wieサイト更新シート

お知らせ・写真・サービス料金・リンクを、メンバーで Google スプレッドシートに書き、代表が確認してからサイトに取り込む仕組みです。
GitHub の鍵（トークン）はどこにも使いません。

## 最初に1回だけやること（代表）

### 1. スプレッドシートを作る

1. Google ドライブ（https://drive.google.com）に `Wieサイト更新シート.xlsx` をドラッグしてアップロードする
2. ダブルクリックで開き、「ファイル」→「Google スプレッドシートとして保存」
3. 5つのタブ（はじめに／お知らせ／写真／サービス料金／リンク）とプルダウンが入っていれば完了
   - CSV（`1_はじめに.csv` など）は同じ内容を1タブずつにしたもの。通常は使わなくてよい

### 2. 写真フォルダを作る

1. Google ドライブに「Wieサイト写真」フォルダを作る
2. フォルダを右クリック →「共有」→ 一般的なアクセスを **「リンクを知っている全員」（閲覧者）** にする
   - こうしておくと、シートにファイル名を書くだけで写真を取り込めるようになります
3. フォルダを開いた状態のブラウザの URL を Claude に渡す（`scripts/sheet-config.json` の `photoFolder` に設定します）

### 3. メンバーに共有する

- スプレッドシートと写真フォルダを、更新を手伝ってくれるメンバーに **「編集者」** として共有する
- それ以外の人には共有しない

### 4. 取り込み用のリンクを作る

1. スプレッドシートの「ファイル」→「共有」→「ウェブに公開」
2. 「お知らせ」タブを選び、形式を **「カンマ区切り形式（.csv）」** にして「公開」
3. 表示された URL をコピーする
4. 「写真」「サービス料金」「リンク」のタブも同じようにして、URL を4つ集める
5. 4つの URL と、写真フォルダの URL を Claude に渡す（`scripts/sheet-config.json` に設定します）

> 「ウェブに公開」したタブは、URL を知っていれば誰でも見られます。
> 連絡先や名簿など、サイトに載せない情報はこのスプレッドシートに入れないでください。

## ふだんの流れ

1. メンバーがシートに書く（書き方はシートの「はじめに」タブ）
2. 代表が Claude に「シートからデータを取ってきて」と頼む
3. Claude が取り込み内容と、確認が必要なこと（日付の形が違う、掲載許可が未確認など）をまとめる
4. 代表が確認して OK を出す → Claude が取り込み・公開する

## 取り込みのルール（Claude 向け）

- 実行: `python scripts/import_sheet.py`（確認のみ）→ 代表の OK 後に `python scripts/import_sheet.py --apply` → `npm run build` → コミット・push
- お知らせ: 「公開」が ○ の行だけ。news.json を **丸ごと置き換える**（シートが正）。日付は `2026.10.15` に揃える。リンクは https:// のみ
  - 1件ごとに `/news/<日付>/`（同じ日付が複数なら `-2`…）の詳細ページができる。開催日時・場所・参加費・定員・申込方法・本文は書いた項目だけ表示。申込方法に https:// の URL があれば「申し込む」ボタンになる
- 写真: 写真欄に書いたものは掲載許可を取ったものとして扱う（「掲載許可」列に「未」とある行だけ除く）。「写真」欄のファイル名を写真フォルダから探して（リンクでも可）取得し、長辺 1600px の WebP にして `public/images/activities/` に保存
  - 活動: `activity-<活動のid>.webp`（同じ名前のサービスページにも使う）
  - お知らせ: `news-<日付>-<行番号>.webp`
  - HEIC は読めないので、JPEG で入れ直してもらう
- サービス料金: シートにあるサービスの料金表だけ置き換え。そのサービスの行がすべて「確定 = ○」なら、サンプル表示を外す
- リンク: note・ラジオは links.json、Instagram・公式LINE は site.json の sns
- 文言は、そのまま取り込まずに一度読む。サイトの文言の方針（ポエムを避ける、個人情報を載せないなど）に合わないものは、代表に確認する

## つながり通信

- 新しい号の PDF を、共有の「つながり通信」フォルダに入れる（ファイル名は `No.4_2027冬号.pdf` の形。先頭の【NEW】は付けても付けなくてもよい）
- 代表が Claude に「シートからデータ取ってきて」（または「通信を取り込んで」）と頼む
- 取り込み: `scripts/sheet-config.json` の `tsushinFolder` のフォルダを読み、PDF をページごとの画像（`public/images/tsushin/<id>/`）にして `src/_data/tsushin.json` を作る（要 pymupdf）。番号の大きい順に並び、いちばん新しい号に「最新号」が付く。表紙を押すとサイト内の拡大表示で読める。同じファイルは作り直さないので、中身を差し替えるときは新しいファイルとして入れ直す
